# RM2027 迁移计划

> 依据：RM2027 规则手册 V1.0.0（20261015）、制作规范 V1.0.0（20261015）
> 状态：等待装甲样式 + 通信协议 + 场地模型
> 更新：2026-10-16

## 一、变更清单

### 1.1 阵容与槽位

| | 2026 | 2027 | 影响 |
|---|---|---|---|
| 地面机器人/侧 | 英雄+工程+步兵×2+哨兵=5 | **重装+步兵×2+哨兵=4** | 槽 10→8 |
| 装甲板 | 固定印刷数字 (1,2,3,4,S) | **点阵屏幕**（样式未发布） | 图案分类器阻塞 |
| 空中机器人标记 | 0x0305 含空中 | **只标地面机器人** | 0x0305 槽数待确认 |
| 多机通信 | 主要发给哨兵 | **可发给所有己方机器人** | 0x0301 扩展 |

### 1.2 场地与雷达

| | 2026 | 2027 | 影响 |
|---|---|---|---|
| 雷达基座高度 | 2.5m | **2.4m** | 相机视角变化 → 外参标定 |
| 场地新元素 | — | 制高点、隧道、机库、工作台 | 地标表 + 网格 mesh 重建 |
| 取消元素 | 飞坡、停机坪 | — | 地标表删除 |
| 功率限制 | — | **750W**（220V 市电） | 硬件预算 |

### 1.3 通信协议

| 命令字 | 2026 | 2027 | 状态 |
|---|---|---|---|
| 0x0305 | 48B（敌6+己6，含空中） | 槽数/格式待确认 | ⏳ 等协议 |
| 0x0301 | 机器人间通信 | 通信范围扩大 | 基本不变 |
| 0x0121 | 雷达自主决策 | 可能保留 | 待确认 |
| 0x020C/0x020E | 标记进度/雷达信息 | P 公式相同 | 大概率不变 |
| 0x0A01-0x0A06 | 信息波/干扰波 | 新增装甲受击信息 | 无线电组关注 |

### 1.4 P 公式（不变）

- 准确 <0.8m / 半准确 0.8-1.6m / 错误 ≥1.6m
- 连击 x 累进：+1.0/+0.5/-0.8
- 0.5s 中断 = 一次错误
- P≥100 → 15% 易伤 / P≥120 → 20% 易伤
- 双倍易伤：累计 1min → 1 次，上限 2 次

## 二、模型重训决策

### 2.1 必须重训（新场地 → 新视觉域）

| 模型 | 重训原因 | 重训方式 | 依赖 |
|---|---|---|---|
| **车 YOLO** | 新场地背景+新视角+新精细度 | 从 2026 checkpoint 精调（形状任务转移性好） | 新渲染序列 |
| **装甲 YOLO** | 点阵屏替代灯条 → red/blue/dead 分类可能失效 | **从零训练**（如果装甲视觉完全变了） | 点阵屏样式 |
| **图案分类器** | 点阵屏显示内容 ≠ 印刷数字 | **从零训练**（输入域完全变化） | 点阵屏样式 |
| **PnP 标定** | 新场地几何 + 新雷达高度 | 重新标定（6+ 地标） | 新场地 CAD |

### 2.2 不需要改

- stub 裁判 P 计分逻辑（公式不变）
- 跟踪器框架（级联匹配、身份投票、发布门）
- 裁判串口骨架（帧格式/CRC 不变，换命令字表）
- Docker 环境
- 海康拉流

### 2.3 正确的全链重训顺序（级联崩塌教训）

```
❌ 错误：单独训/换任一模型 → 下游因 ROI 域偏移而崩塌

✅ 正确：
  1. 新 Blender 场景 + 新雷达位姿 → 渲染训练序列
  2. 训车 YOLO（从 2026 checkpoint 精调）
  3. 用新车模型收割装甲训练数据（render_armor_crops.py）
  4. 训装甲 YOLO
  5. 用新装甲模型收割图案训练数据（render_pattern_crops.py）
  6. 训图案分类器（从零，因点阵屏是新域）
  7. 全部一起换入 → 基准回放验证
```

预计总耗时（5070 台式机）：
- 渲染 3 序列 × 200 帧 = ~30 分钟
- 训车 YOLO 20 epochs = ~3-5 小时
- 收割装甲 + 训装甲 = ~1 小时
- 收割图案 + 训图案 = ~1 小时
- 基准验证 = ~30 分钟
- **总计：~6-8 小时（一个完整训练日）**

### 2.4 雷达高度变化的影响

| 变化 | 对策 |
|---|---|
| 基座 2.4m（vs 2.5m） | 相机外参微调 → PnP 重新标定即可 |
| 场地更精细 → 背景纹理变化 | 训练数据域变化 → 全模型重训 |
| 新地标（制高点/隧道/机库） | PnP 标定利用新地标；可能的遮挡影响跟踪 |

## 五、新场地到位后的操作序列

```bash
# 1. 导入新场地模型
#    - 更新 scene/RMUC2027_radar.blend
#    - 设置雷达相机位姿（2.4m 高度）
#    - 验证：渲染一帧确认视野

# 2. 渲染训练序列（三种运动模式）
python scene/armor_assets/generate_radar_car_sim.py --motion patrol --count 200 --dt 0.1
python scene/armor_assets/generate_radar_car_sim.py --motion patrol --count 200 --dt 0.1 --spin 6.0

# 3. 训车 YOLO（从 2026 checkpoint 精调）
python -m models.train car --data models/configs/data_car_2027.yaml --imgsz 1280 --batch 8 --epochs 20

# 4. 收割装甲训练数据（用新车模型）
python dataset/render_armor_crops.py --seq scene/locate_out/videoseq_2027 --tag 2027

# 5. 训装甲 YOLO
python -m models.train armor --data models/configs/data_armor_2027.yaml --imgsz 192 --batch 64 --epochs 60

# 6. 收割图案训练数据（等点阵屏样式后）
python dataset/render_pattern_crops.py --seq scene/locate_out/videoseq_2027 --tag 2027

# 7. 训图案分类器（从零）
python -m models.pattern --data dataset/pattern_2027 --epochs 100

# 8. 导出 + 换入 + 基准验证
python tools/pt_to_engine.py      # 车
python tools/pt_to_engine.py      # 装甲
python tools/pattern_to_engine.py # 图案
# 全部换入后跑基准
python scripts/run_radar.py
python scripts/score_referee.py
```
